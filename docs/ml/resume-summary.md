# Resume summary

Generated by `ml/report.py`; every number is from `ml/artifacts/metrics.json`, on a frozen test set of merchants never used in development. All are agreement with LLM teacher labels on synthetic narrations.

Built a transaction categoriser for Vaulta, an Indian personal-finance app, by knowledge distillation: two LLMs on Groq labelled stripped merchant names (a third broke ties) from a 130-subcategory taxonomy, and a 21,542-n-gram character TF-IDF + logistic-regression model (0.75 MB gzipped, identical in the browser and in Python) learned from 19,615 synthetic bank narrations. On a frozen set of merchants never used in development it cut the share of transactions sent to manual review from 85.6% to 51.3% for new brands and from 86.4% to 23.1% for new local shops, agreeing with the teacher on 89.4% and 96.2% of the rows it filed, with a threshold set on validation only. Includes calibration (ECE 0.0477), per-user correction memory, reversible re-categorisation and opt-in retraining gated on frozen test sets; a 16 MB multilingual embedding alternative was evaluated and rejected.
