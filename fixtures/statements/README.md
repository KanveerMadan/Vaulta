# Statement fixtures

Shared by `backend/tests/test_reference_parsers.py` and `frontend/src/import/*.test.js`.

- `*.csv` — hand-written in each bank's CSV layout, as `csv_parser.py` expects it.
- `*.pdf` — generated by `make_fixtures.py` with pymupdf. **Synthetic**: the
  layouts follow each statement's format as far as it is known, but none of
  them is a real export. The Google Pay layout is the one the Python parser
  was verified against; PhonePe, Paytm, the bank-account PDF and the four
  credit-card statements are unverified against real files.
- `expected.json` — output of the Python reference parsers on these files
  (regenerate with `cd backend && venv/bin/python ../fixtures/statements/make_fixtures.py`).

All names, numbers, VPAs and account details are made up.
